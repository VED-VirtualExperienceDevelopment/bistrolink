# Marcas de terceros

## `mercado-pago.svg`

Logo oficial de Mercado Pago, versión horizontal a color para uso digital (RGB), del kit de marca «Logos de Mercado Pago», versión marzo 2025.

- Fuente: <https://www.mercadopago.com.ar/mp/logo-oficial> (archivo `MP_RGB_HANDSHAKE_color_horizontal.svg`).
- Se usa tal cual lo entrega Mercado Pago: la guía del kit pide no editar el contenido del SVG. No se redibuja, no se recolorea y no se le recorta el margen.
- Uso en BistroLink: sello de pago seguro arriba del formulario de tarjeta (HU-051, BL-563), sobre fondo blanco.
- Es una marca registrada de Mercado Pago. No forma parte de la licencia del código de este repositorio.

Las imágenes de las tarjetas (Visa, Mastercard, OCA, …) no se guardan acá: las sirve Mercado Pago (`secure_thumbnail` de `/v1/payment_methods`).
